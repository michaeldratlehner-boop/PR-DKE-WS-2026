## Verwendete Technologien

- React: JavaScript-Bibliothek zur Entwicklung der Benutzeroberfläche
- Vite: Entwicklungs- und Build-Tool für React
- Node.js: JavaScript-Laufzeitumgebung
- npm: Paketmanager zur Installation der Abhängigkeiten

## 1. Voraussetzungen

Node. js auf dem Computer installieren

https://nodejs.org/


Überprüfen, ob die Installation erfolgreich war:

        node -v
        npm -v


## 3. Frontend einrichten
Im IntelliJ-Terminal vom Hauptordner aus
in den Frontend-Ordner wechseln:

    cd frontend

Abhängigkeiten installieren:

    npm install

Dadurch werden die benötigten Pakete aus
package.json installiert.

## 4. Frontend starten

        npm run dev

Anschließend auf den Link klicken.
